# AlamTech Labs — Software & Web Application Agency

A modern, high-performance software agency website built for **Md Mashood Alam** to showcase expertise in:
- **Enterprise Backend**: Java, Spring Boot 3.x, Microservices, RESTful APIs, Spring Security
- **Frontend Architecture**: React.js, Tailwind CSS, Component Systems, High-Conversion UX
- **Cloud & DevOps**: AWS (EC2, S3, RDS, VPC, Lambda), Docker, CI/CD
- **Databases & Security**: MySQL, PostgreSQL, JWT/OAuth2, AES-256-CBC Encryption

## 🛠️ Quick Start

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## ⚙️ Configuration
All website copy, services, projects, pricing, and contact details are centralized in:
`src/data/agencyData.js`
